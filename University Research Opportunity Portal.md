# University Research Opportunity Portal



A full-stack web application designed for students and faculty to post, view, and manage university research opportunities.

##### Technologies used:

* Frontend:HTML5, CSS, JavaScript
* Backend: Node.js
* Database: MySQL
* XAMPP for creating database



##### Features:

* Post new research opportunities via an interactive form.
* View all available opportunities in a dynamic table.
* Delete existing opportunities.



##### How to Run:

1. Start the MySQL database and ensure the table **'opportunities'** is set up.
2. Run the backend server: `node server.js`
3. Open index.html using Live Server or your browser.
